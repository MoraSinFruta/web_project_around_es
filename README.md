# Around The World.

## Descripción del Proyecto
Este proyecto es una aplicación web interactiva que permite a los usuarios compartir fotografías de diversos lugares, darles "Me gusta" y administrar su propio perfil. El objetivo principal de esta etapa ha sido configurar la estructura inicial de la lógica del lado del cliente utilizando JavaScript, asegurando una correcta vinculación con el documento HTML y el manejo estructurado de datos dinámicos mediante arrays y métodos de iteración.

## Tecnologías Utilizadas
* HTML5
* CSS3 (Metodología BEM)
* JavaScript (ES6+)

## Funcionalidades Implementadas
* Vinculación del script principal utilizando carga diferida para optimizar el rendimiento de la página.
* Creación de un conjunto de datos inicial estructurado en un array de objetos con propiedades específicas para nombres y enlaces de imágenes.
* Implementación de ciclos de iteración mediante métodos modernos de JavaScript para el procesamiento seguro de los elementos de datos.

## Estructura del Directorio
* /blocks — Contiene los archivos CSS organizados por bloques según la metodología BEM.
* /images — Almacena los recursos gráficos y vectores del proyecto.
* /pages — Contiene los estilos generales y el punto de entrada de CSS.
* /scripts — Carpeta destinada a los archivos de lógica de JavaScript.
