# Around The U.S.

## Enlace del Proyecto
* [Ver proyecto en vivo en GitHub Pages](AQUÍ_PEGA_TU_ENLACE_DE_GITHUB_PAGES)

## Descripción del Proyecto
Este proyecto es una aplicación web interactiva que permite a los usuarios compartir fotografías de diversos lugares, darles "Me gusta", eliminar elementos de la galería y administrar la información de su propio perfil a través de ventanas emergentes dinámicas.

## Tecnologías Utilizadas
* HTML5
* CSS3 (Metodología BEM)
* JavaScript (ES6+, Manipulación del DOM y eventos nativos)

## Funcionalidades Implementadas
* Renderizado dinámico de tarjetas utilizando elementos `<template>` a partir de arreglos de datos.
* Apertura de imágenes a pantalla completa en un componente de previsualización adaptativo.
* Procesamiento seguro de formularios para la actualización del perfil de usuario y adición de nuevos lugares de interés en tiempo real.
* Interactividad independiente para las funciones de marcado "Me gusta" y eliminación de tarjetas.

## Estructura del Directorio
* /blocks — Archivos CSS estructurados por componentes independientes según BEM.
* /images — Almacén de recursos gráficos, vectores e imágenes de respaldo.
* /pages — Estilos globales de la página.
* /scripts — Lógica principal de ejecución de JavaScript (`index.js`).
